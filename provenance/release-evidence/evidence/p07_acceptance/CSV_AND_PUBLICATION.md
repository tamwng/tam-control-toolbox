# Proposed representation, source and publication safeguards (P13)

The source table producers use `writetable`. MathWorks documents text numeric output as long-g, and long-g as 15 significant digits for doubles (7 for singles). This is a representation fact, not the origin of any scientific tolerance. [writetable documentation](https://www.mathworks.com/help/matlab/ref/writetable.html), [format documentation](https://www.mathworks.com/help/matlab/ref/format.html).

Use comma explicitly; quoted fields use doubled double-quotes; decimal point is dot, with no thousands separators. Keep raw tokens/bytes and exact header/column/row order. Freeze types by the observed study/table schema, including header-only/zero-byte empty tables; do not infer delimiters from Windows backslashes. Identifiers remain identifiers. Reject unexpected columns, duplicate keys/headers, malformed numeric tokens, missing required data or ambiguous source/unit mappings. Preserve the prior metadata-parser issue explicitly: two paper source-path exports must not auto-detect backslashes as column delimiters.

`csv_mat_binding_plan.csv` covers all **84** existing CSV families, with the exact producing reducer/selection authority and their saved MAT support. ## Explicit proposed encoding arithmetic

For finite nonzero real binary64 v written by the verified 15-significant-digit emitter, define `q15(v)=0.5*10^(floor(log10(abs(v)))-14)`. Include one binary64 parse/representation ulp as `e15(v)=q15(v)+eps(abs(v))`, using outward arithmetic near decade/subnormal boundaries. For exact zero, require a zero token and use e15=0. Nonfinite strings/masks/signs and integer/identifier columns are exact. Unknown emitter, overflow/underflow ambiguity or unsupported numeric class blocks; do not infer significant precision merely by counting visible trailing digits. The expression is a decimal-encoding budget, not a manuscript rounding criterion.

Where the unrounded own-run MAT scalar v exists, prefer verifying that the raw token represents v under the known 15-digit encoder; retain the exact encoding/parse delta and require it <=e15(v). Direct selected MAT values retain their exact own-run source relationship. Scientific cross-run agreement uses the **unrounded** values and their approved quantity rule.

Where a historical aggregate has only its known-precision CSV representation, propose a separately labeled `SERIALIZED_SCALAR_COMPARISON_WITH_MAT_SOURCE_SUPPORT`: if the underlying scalar contract is `abs(a-b)<=A+R*abs(b)`, require

`abs(a_csv-b_csv) <= A + R*abs(b_csv) + e15(a_csv) + (1+R)*e15(b_csv)`.

This additive representation allowance is algebraic propagation of two decimal encodings; it is not chosen from observed output differences. It does **not** establish equality of unknown unrounded historical aggregates. Required underlying MAT fields and declared reduction/source bindings still gate, and the evidence must identify the missing historical unrounded scalar. If an author requires unrounded historical scalar verification for a particular claim, its absence remains MISSING/BLOCKED rather than being hidden behind CSV precision. Author approval of this treatment is part of consolidated P13.

Before freezing the implementation, test the actual producer/reader on zero, signed values, scientific notation, decade boundaries, subnormals, 15/17-digit representations, NaN/Inf, empty tables and quoted Windows paths. Validate all table bindings and column-specific units. New comparator evidence should explicitly use `%.17g` and/or hexadecimal binary64 plus MAT data. The current review's arithmetic MAT is authoritative; the accompanying display CSVs from `writetable` are 15-digit views, so adjacent boundary-test doubles may look the same there.

## Publication claims are separate gates

Require exact case/window/horizon/model/metric/source selection and sample/applicability/denominator counts. Preserve Table 12's six models, five horizons, 30 rows and 29 queries per row; preserve A.14's 503 primary control runs and the distinct covariance/QP counts. Study 6 same-run sources must be the five fresh parents at the new candidate/policy, not historical fallback.

Apply unrounded scalar/contrast rules separately after parent-array checks. RMS uses state units; squared errors and cross terms use squared state units. P11 proposes exact sign of each reported signed contrast and exact zero-containment classification of its interval, with all raw endpoints and differences retained. Report every ordering reversal and preserve any exact selected-argmax index. For an explicitly claimed strict ordering, require the claim to remain true on both runs; if the accepted numerical uncertainty envelopes overlap the claim boundary, mark the claim UNRESOLVED and return it for the consolidated audit, not as a reproduced conclusion. Do not invent claims about unreported orderings.

Before release, the author must confirm the exact claim/precision mapping from the existing paper/result map to these quantities. Record changed displayed digits as review evidence, but never pass a number merely because manuscript rounding matches. The reproduction requirement, raw discrepancy, serialization error and publication interpretation are four distinct records. No manuscript was readjusted or edited in this pass.
