# Units, applicability and explicit dispatch

This document defines the grouped proposals, not a new scientific implementation. A1–A5 are author-approved agreement requirements; P1–P13 remain inactive proposals. The numerical scales below are selected reproduction scales, not claims about optimizer/integrator error. No scale is computed from a candidate/reference discrepancy.

**Common predicate:** for real double arrays with identical class and shape, apply `abs(a-b) <= alpha*U + beta*abs(b)` to every applicable finite element. This is one additive inequality. An OR of absolute/relative predicates, a mean error, or checking only the first plan action is different and prohibited. Broadcast U only when its component units are explicitly defined; numerical and mathematical dimensions must both match.

**Applicability precedes arithmetic.** Exact own-run status/masks identify required outputs. For QP fields, accepted origin j<=nSteps requires all N-1 planned inputs, all N planned outputs and both output-slack rows at every horizon to be finite. `uNext` is the selected first decision, not the committed input in the first predicted transition. For rejected or unexecuted origins, preserve the explicit stored non-applicable slots, rejection/events and fallback relation; matching NaNs are recorded as NOT_APPLICABLE, never counted as successful plans. Inf signs and NaN/finite masks remain exact across runs. Required nonfinite outputs fail even if both runs contain the same nonfinite value. Known-model empty covariance and unavailable identity diagnostics use their existing explicit applicability definitions.

**Own-run relationships are distinct.** `u(j+1)` must exactly equal its own accepted `plannedInput(1,j)`; on rejection it equals the committed input. Checkpoint arrays exactly equal their selected history slices. Study 6 retained run copies equal their fresh parent arrays exactly. Do not turn a separately calculated identity into an exact-copy check: e.g. planned first output versus separately calculated prediction retains its existing numerical identity check, because those are two calculations. Source arrays/row selections are exact; a new cross-run agreement rule does not waive those relationships.

## Scalar variable and coefficient unit resolver

- Studies 1, 3, 4 and P06 use Plant A; Study 2 uses Plant B; Study 5 uses Plant C. Study 6 must dispatch using `out.meta.plant`, `meta.unit`, exact sourceStudy/modelId and row unit metadata. `constraint_audit.mat` contains exact copies of four Plant B constraint runs; no Plant C assumption is allowed there.
- A/B: X=one dimensionless state/output unit, U=one dimensionless input unit. C: X=1 rad/s, U=1 N m. Slack is X for each existing +y/-y bound row. Raw slack is never multiplied by `Seps=1e4*eye(2)` for comparison.
- Current scalar QP scope requires m=p=1, `Hy=[1;-1]` and the unweighted `-I` slack block in `assemble_qp.m`. `plannedInput` has N-1 rows, `plannedOutput` N, `slack` 2-by-N; origin dimensions and cfg.N are exact. A different Hy coefficient, variable scaling, unknown unit, vector input/output or unexpected shape is UNSUPPORTED_SCOPE, not permission to silently convert units.
- Frozen A has X/X; B has X/U; c has X. For a scalar direct feature `x^p*u^q`, its coefficient has X^(1-p)*U^(-q). The Plant C affine/P3 ordered powers are `[0,0;1,0;0,1;2,0;1,1;0,2;3,0;2,1;1,2;0,3]` (affine uses the first three). Plant C model D features `[u,x^3]` give coefficient units X/U and X^(-2). Plant C I/K coefficients retain `[J,d_C] = [kg m^2, N m/(rad/s)^3]`. A/B model dictionaries use their stored order/sharing in their dimensionless coordinates. Missing model/order information blocks dispatch.
- `D_i` is the RMS of `rowScale*Phi_i`, so its unit is row-scaled feature i; `beta_i=D_i*theta_i` has row-scaled response units. For Plant C model I, rowScale=1/Ts, scaled response is N m, raw `idResponse=Ts*u` is N m s, and raw regressor components are X and X^3 s. Thus D components have X/s and X^3. For known physical model K, rowScale=1: beta has N m s; its empty covariance is not applicable. For C direct models, rowScale=1 and beta/residual have X. These are not pooled physical parameter units.
- `RlsEstimator` residual is `rowScale*b - normalizedRegressor*beta`. Its forgetting energy is `sqrt(mean(residualSquares))/sigma`, dimensionless. It is **not** a squared-error quantity. Lambda is dimensionless; configured fixed/none values and branch outcomes stay exact.
- Normalized regressor R, G=R'*R/m and its inverse-information P have dimensionless numerical information coordinates; P is not a physical statistical covariance of theta. QP H condition uses its existing decision/slack coordinates and penalty weights without new scaling.
- Plant C integral/trapezoid values have X^3 s. The stored physical equation residual divides the torque impulse residual by Ts, hence N m. State and predictor-Jacobian refinement rows use X, X/X and X/U as appropriate.

All U values above mean **one unit in the declared coordinate**, not a data-dependent rescaling of the scientific problem. Matrix norm scaling is used only where explicitly specified in P4/P5/MATRIX_RULES.md. A1's identical-D prerequisite remains exact; P3 cannot silently relax it.

## Metric dispatch

Use exact study, table, field and (when present) metric/parameter/phase/unit row keys; a field called `maximum`, `estimate` or `median` does not define a unit by itself. The 4,195-row coverage map supplies explicit scope and original subgroup. Unknown combinations block; there is no generic floating-point fallback.

- RMS, mean error, absolute peak, quantile, IQR and paired differences carry their underlying variable's unit. RMSE has X, while MSE, squared identity and signed cross terms have X^2. A signed cross term is not made positive or square-rooted.
- Input RMS, mean absolute increment and total variation have input units. Mean increments are per transition; no division by Ts. P10 deliberately proposes a separate scalar agreement requirement, not a claim that accepted elementwise budgets imply it. Original sample membership and denominators must match exactly.
- Violation magnitudes use the constrained variable unit; counts and thresholds stay exact. `predictedSlackMax`, selected upper/lower slack and first-step diagnostic quantities are **outside A5** and belong to P10, with exact within-run parent selection first.
- A.14 numerical minimum/median/maximum rows use P6 in condition-number units; exact `quantity` separates RLS covariance from QP Hessian. Exact extrema case/index stays required.
- `parameterScaledPercent` and related fields use the source's frozen `100*norm(raw error)/sqrt(n)` definition. For Plant C it mixes unlike parameter coordinates: report it as a legacy numerical coordinate score, not a physically homogeneous percentage or relative parameter error. P10 proposes one legacy-score unit as its absolute unit scale; J and d components are separately checked under P2. Do not revise the stored score or manuscript in this task.
- `archiveComparisonMax` mixes state and squared-state differences in a legacy numeric maximum. P12 explicitly handles it as bookkeeping with separately gated components, never as a single physical norm.
