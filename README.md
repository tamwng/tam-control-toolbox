# Structure-Informed Indirect Adaptive Predictive Control

Reusable MATLAB core for the revised EJC manuscript, *A Numerical Investigation of Indirect Adaptive Predictive Control with Structure-Informed Nonlinear Regressors*.

From the repository root in a clean MATLAB session:

```matlab
run_tests
run_verification
```

Both commands establish repository-local paths and fail explicitly if required checks fail or remain incomplete. `run_verification` runs the same test suite, including its independent mathematical checks. MATLAB and Optimization Toolbox are required; the tested environment is R2026a Update 5.

- `src/`: ordered models, fixed scaling, RLS, nonlinear reconstruction, frozen affine prediction, constrained QP, and committed-input controller.
- `tests/`: deterministic analytical, batch, numerical, and end-to-end fixtures.

At time k, the measured transition was generated by u(k-1), u(k) is already committed, and the controller computes u(k+1). Raw RLS estimates remain separate from parameters mapped for prediction. Rejected control computations hold u(k+1) = u(k).

This phase verifies the numerical core only. Numerical studies and paper-result reproduction are not included. The earlier implementation and its examples remain available in Git history.
